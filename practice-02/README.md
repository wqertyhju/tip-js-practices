## Задание 2. Модель данных и создание задачи

Модель задачи: `{ id, title, completed, priority }`.

Правила:
- id — `Number.isSafeInteger(id) && id > 0`;
- title — строка, после `trim()` длина 1..100;
- completed — boolean, при создании всегда `false`;
- priority — `"low" | "medium" | "high"`, по умолчанию `"medium"`.

Функция `createTask` возвращает `{ ok: true, task }` при успехе и `{ ok: false, error }` при ошибке.

Все обязательные проверки пройдены (см. `checks.js`, секция `createTask`).
